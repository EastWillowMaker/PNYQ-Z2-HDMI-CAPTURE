# Third 1080p30 loop build: reset association still rejected

Revision `b097ae9` was exported to `artifacts/1080p30-source-003` and built
from scratch in `artifacts/1080p30-loop-003`, with console output retained at
`artifacts/1080p30-loop-003.console.log`. HLS synthesis/export and drain checks
passed. The build again stopped at block-design validation and produced no
bitstream.

Vivado reported `BD 41-1343`: the pattern's pixel-clock reset input was
connected to `serializer_reset`, which it inferred as synchronous to the
serial clock. This persisted after the module clock declarations used
`ASSOCIATED_ASYNC_RESET`. The declarations alone therefore do not resolve the
integration defect. No warning was waived and the board was not reconfigured.
A reduced TX-only BD test is the next diagnostic step; actual synthesis,
timing, CDC/DRC and board tests remain unexecuted for this source revision.
